# student-expense-analysis
This project analyzes student spending patterns using Python, Pandas, and visualization libraries. It includes data preprocessing, statistical analysis, and visualizations such as bar charts, pie charts, and heatmaps to identify trends and correlations in expenses.
# Student Expense Analysis

## 📊 Project Overview
This project analyzes student spending patterns using Python, Pandas, Matplotlib, and Seaborn.

## 🔍 Features
- Data analysis (mean, max, min)
- Gender & education distribution
- Highest spending category
- Correlation analysis
- Multiple visualizations (bar, pie, heatmap)

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📈 Key Insights
- Identified highest spending students
- Analyzed category-wise expenses
- Visualized correlations between variables
