# 📊 Student Expense Analysis

## 📌 Project Overview

This project analyzes student spending patterns using **Python and data analysis libraries** to uncover trends, correlations, and key insights. The goal is to understand how students allocate their expenses across different categories.

---

## 🎯 Objectives

* Perform **data cleaning and preprocessing**
* Analyze spending behavior using **Exploratory Data Analysis (EDA)**
* Identify key patterns in student expenses
* Visualize data using effective charts

---

## 🛠️ Tools & Technologies

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**

---

## 🔍 Features

* Data preprocessing and cleaning
* Statistical analysis (**mean, max, min**)
* Gender and education distribution analysis
* Identification of highest spending categories
* Correlation analysis between variables
* Multiple visualizations:

  * 📊 Bar Charts
  * 🥧 Pie Charts
  * 🔥 Heatmaps

---

## 📈 Key Insights

* Identified major spending categories among students
* Observed variations in spending patterns across demographics
* Detected relationships between different expense variables
* Highlighted high-spending trends and behavior
